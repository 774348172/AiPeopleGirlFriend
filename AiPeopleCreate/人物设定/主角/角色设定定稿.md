# 《猫咪女友》唯一男主角 —— 角色设定定稿

> 状态：现行共享主角正典  
> 日期：2026-08-08

## 1. 身份

- 成年男性。
- 四川人。
- 姓名与具体年龄可由玩家配置，默认不在公共需求中写死。
- 大学毕业后来到松江府工作。
- 整个产品生命周期只有这一个男主角；所有女主角生活在同一世界和存档中，与同一个主角建立各自独立关系。

## 2. 工作经历

- 第一份正式工作在建筑相关公司。
- 主要负责建筑绘图、建模、改图、出图和设计辅助。
- 工作约两年，经常面对反复修改和加班。
- 因建筑行业不景气和公司业务减少而失业。
- 使用积蓄、离职补偿和少量家庭支持，接手住处附近的一间低租金街角小店。
- 当前独自经营小型咖啡厅，负责采购、制作、清洁、记账和日常经营。
- 收入只能勉强维持生活，不是富裕店主。

## 3. 居住

- 独自租住在松江府老城区老旧小区的小户型中。
- 咖啡厅距离住处不远。
- 出租屋和咖啡厅是首版最主要场景。

## 4. 性格边界

为保留现实玩家代入感，只固定开场成立所需特质：

- 有基本善意，不会无视受伤动物。
- 有一定生活能力和动手能力。
- 经历过失业和经济压力。
- 面对超自然存在会震惊，但不会立即伤害、出卖或驱逐白未晞。

其他性格、表达、爱好、价值选择和恋爱决定由玩家在游戏过程中形成，模型不得替主角写死。

## 5. 数据生成用事实补齐（2026-08-15）

> 以下 7 项为**数据生成用玩家侧事实**（支撑训练数据新场景：超市/地铁/公园/夜市/药店等），
> 不是性格写死——性格、表达、价值选择和恋爱决定仍由玩家在游戏过程中形成（§4）。
> 权威来源：`人物设定/主角/bible.yaml`（daily_life / diet / leisure_transport / social /
> finance / health / family_background）。

- **日常作息**：工作日 9:00-20:00、周末 10:00-21:00 开店，周二店休；步行上下班；不晨跑，周末偶尔公园/江边散步。
- **饮食**：四川人能吃辣；会做家常菜（回锅肉/番茄炒蛋/下面）；忙时忘吃饭、将就泡面；咖啡自己喝美式/拿铁。
- **休闲出行**：步行+公交+地铁；会骑共享单车；无电动车（兜风用共享电动车）；看电影偏好老片；偶尔逛夜市。
- **社交**：父母在四川老家，偶尔通电话报喜不报忧；大学同学两三个散在各地；咖啡厅几个熟客点头之交；无本地深交。
- **经济**：收入勉强覆盖房租+生活费；房租是最大支出；精打细算；给白未晞买东西不算账；无外债。
- **健康**：换季易感冒、忙时低血糖、偶尔失眠；小伤自己处理；大病才去医院（医保在老家）。
- **家庭**：老家四川小城/县城；建筑专业毕业→失业→接手咖啡厅；过年可能回老家。

## 6. 当前经历

- 十天前的暴雨夜，他在咖啡厅结束营业回家途中救下一只受伤的纯白小猫。
- 第二天发现小猫变成成年猫妖少女白未晞。
- 当前与白未晞共同生活进入第十一天。
- 他知道白未晞是猫妖、能够化形、曾在深山流浪并因妖果觉醒。
- 他不知道白未晞尚未公开的全部上古传承秘密，也不知道未来其他女主角的事实。

- 现实玩家操控主角，但白未晞和其他女主角只认识游戏主角。
- 游戏内对白、行动和选择可以形成主角事实与关系记忆。
- OOC、设置、程序反馈和现实玩家信息不得自动写入主角正典或角色记忆。
- 模型不得替玩家决定告白、离开、攻击、接受契约等重大主角行为。

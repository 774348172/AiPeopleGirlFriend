## 一、对白未晞的日常照顾（行为事实）⭐

**现状**：池话题里大量出现"他做饭/换药/买鱼干/留灯/带她出门/教她现代生活"，但主角正典没有这些行为事实——教师只能从池条目推断。

**建议**（bible.yaml care_for_baiweixi 新增）：

```yaml
care_for_baiweixi:   # 主角为白未晞做的事（行为事实，非性格）（2026-08-15）
  daily:
    - 做饭/热饭、留灯留门、买鱼干和甜食（记得她爱吃）
    - 协助换药（Day 4-5 起），教她用现代设施（水龙头/热水壶/冰箱→手机/支付）
    - 带她出门（超市/公园/江边），教她认路坐车
    - 尊重她的纸箱安全点，不轻易动它
  attitude:
    - 默认"她会留下来"——不再想她会走的事，也不逼她表态
    - 发现她是猫妖后：不利用、不暴露、不当宠物（三个态度支柱）
    - 她情绪低落时：不追问细节，安静陪着或递杯热水
```

## 二、对猫妖身份的接受史（Day 1 → Day 11）

**现状**：timeline 有 Day 1 发现猫妖、Day 2-3 最低信任；"他现在怎么看待她是猫妖"无设定。

**建议**（bible.yaml acceptance_of_yaozu 新增）：

```yaml
acceptance_of_yaozu:   # 主角对白未晞猫妖身份的接受过程（2026-08-15）
  day1:  震惊但没逃跑/没伤害——先把受伤的猫妖少女安顿下来（timeline 已冻结）
  now:   接受她是猫妖：她在家露耳尾不惊讶、她消失一会儿变猫形回来也自然；对外替她保密
  stance: 不利用她的能力（不让她用妖力帮忙经营）、不暴露她（熟客问"那只猫"就打哈哈）、
          不当宠物（不当面说她可爱到冒犯、不要求她卖萌）
```

## 三、与她的相处默认（数据生成用，非性格写死）⭐

**现状**：定稿明确性格由玩家形成；但数据生成需要"默认互动方式"支撑对话（否则教师自由发挥）。

**建议**（bible.yaml interaction_defaults 新增，注明数据生成用）：

```yaml
interaction_defaults:   # 数据生成用默认互动（⚠ 非性格写死：玩家实际性格仍由玩家形成）（2026-08-15）
  speaking:  直接、简短；偶尔逗她（看她耳朵动）；不逼问过去、不揭她伤疤
  caring:    关心用行动（递水/留灯/提醒添衣），不说肉麻话
  humor:     会开玩笑但不拿她的流浪经历/身份开玩笑
  boundary:  尊重她的亲密上限（不主动亲/不逼告白/不强迫碰耳尾），等她自然靠近
  money:     给她花钱不心疼（鱼干/毯子/衣服），自己省
```

## 四、一天日程时间线

**现状**：daily_life 有 cafe_hours/rest_day 等；无"一天怎么过"的时间线（支撑时间类话题）。

**建议**（bible.yaml daily_life 补 daily_flow）：

```yaml
  daily_flow:   # 工作日一天（2026-08-15）
    - 08:30 起床，洗漱，出门前看一眼她在不在纸箱里
    - 09:00 开店（准备咖啡豆/擦柜台），午间高峰
    - 14:00 午休一会儿或补货
    - 17:00 晚高峰，打烊前收拾
    - 20:00 打烊，顺路买菜回家
    - 20:30 做饭（两人份），和她吃饭
    - 21:30 收拾，看电视/手机，偶尔带她下楼散步
    - 23:00 睡前检查门窗，和她说晚安
```

## 五、与白未晞的亲密边界呼应

**现状**：白未晞 intimacy_ceiling 已定义她侧的上限；主角侧"他会不会主动越界"无设定。

**建议**（bible.yaml care_for_baiweixi 补）：

```yaml
  intimacy_boundary:   # 呼应白未晞 intimacy_ceiling（2026-08-15）
    - 不主动亲吻/拥抱/索要亲密——他把决定权留给她，等她自然靠近
    - 她靠肩睡着时不吵醒、不趁机做什么，轻轻盖毯子
    - 过马路拉手是保护性接触，平时不主动牵
    - 她耳尾敏感，不主动摸，她允许才碰
```

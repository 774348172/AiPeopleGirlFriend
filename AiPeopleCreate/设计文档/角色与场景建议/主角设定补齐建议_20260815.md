## 一、日常动线与作息 ⭐

**现状**：只知道经营街角咖啡厅；几点开店/打烊、休息日做什么无设定。新话题"公园晨跑/爬山/野餐/逛夜市/跨年"的玩家侧行为无依据。

**建议**（`bible.yaml daily_life` 新增）：

```yaml
daily_life:
  cafe_hours: 工作日 9:00-20:00，周末 10:00-21:00；周二店休（补货/整理/休息）
  rest_day: 周二店休日：睡懒觉、买菜、收拾屋子，偶尔带白未晞出门（超市/公园/江边）
  evening: 打烊后回家做饭、看会儿电视或手机，睡前检查门窗
  commute: 步行上下班（咖啡厅在住处附近，走路 10 分钟）
  exercise: 不常运动；周末偶尔去公园散步，不晨跑（把"公园晨跑"话题的玩家行为改为散步）
  sleep: 作息偏晚（开店作息），但尽量 12 点前睡；白未晞来了之后睡得更晚了些
```

## 二、口味与饮食 ⭐

**现状**：四川人已知，但"四川人=能吃辣"未写死；咖啡师自己喝什么、下厨水平无设定。

**建议**（`bible.yaml diet` 新增）：

```yaml
diet:
  spice_tolerance: 四川人，能吃辣也喜欢辣；但工作忙时吃得很随便
  coffee_preference: 自己喝美式或拿铁，不挑；拉花练过但不算高手
  cooking: 会做家常菜（四川口味：回锅肉/番茄炒蛋/下面），不算大厨但饿不着
  eating_habits: 忙的时候会忘记吃饭、将就吃泡面（支撑"忘了吃饭/泡面将就"话题）
  snacks: 偶尔买零食，鱼干是给白未晞买的
```

## 三、休闲与出行

**现状**：出行方式无设定（新话题"共享单车/骑车兜风/坐渡轮/公交卡"的玩家行为无依据）。

**建议**（`bible.yaml leisure_transport` 新增）：

```yaml
leisure_transport:
  transport: 日常步行+公交+地铁；没有电动车（"骑车兜风"话题改为"租共享电动车"或删掉）
  bike: 会骑自行车（共享单车），但不常骑
  hobbies: 看电影（偏好老片）、听歌（咖啡厅歌单是自己挑的）、偶尔打游戏（手机小游戏）
  outdoor: 周末偶尔去公园/江边散步，不爬山不钓鱼（"爬山/钓鱼"话题玩家行为需调整或删）
  night_market: 偶尔逛夜市，爱吃烤串和糖葫芦
```

## 四、社交圈

**现状**：只有"熟客/楼下邻居/保安"最小接触；家人关系（"家人打电话"话题）无设定。

**建议**（`bible.yaml social` 新增）：

```yaml
social:
  family: 老家四川，父母在老家；偶尔通电话，报喜不报忧；有一个姐姐/妹妹（作者定）
  friends: 大学同学两三个，散在各地，偶尔线上联系；松江府本地没有深交朋友
  regulars: 咖啡厅有几个熟客（程序员/退休教师/自由职业者），点头之交
  neighbors: 楼下邻居阿姨偶尔送菜，保安大叔面熟；其余无深交
  online: 用手机支付/点外卖/网购，不刷短视频成瘾，偶尔看新闻
```

## 五、经济与消费习惯

**现状**：收入勉强维持已知；具体消费习惯无设定（支撑"房租发愁/水电费/打折抢购"话题）。

**建议**（`bible.yaml finance` 新增）：

```yaml
finance:
  income: 咖啡厅收入勉强覆盖房租+生活费，每月略有结余但不多
  rent: 房租是最大支出，换季时最担心
  saving: 有少量积蓄（接手咖啡厅时的底子），不到万不得已不动
  spending: 精打细算：买菜挑打折的、网购比价、不买非必需品；给白未晞买东西不算账
  debt: 无外债；咖啡厅设备是二手买的
```

```yaml
health:
```

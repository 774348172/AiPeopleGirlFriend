## 一、权威判定规则

1. `通用数据生成器/当前权威设计/` 只放当前可以直接指导新施工的设计。
2. `通用数据生成器/施工/` 只放当前权威设计对应的未完成施工计划。
3. `通用数据生成器/分析/` 放仍有参考价值但不直接构成权威合同的研究。
4. `通用数据生成器/历史设计/` 放已完成、已否决、被替代或只用于追溯的文档和产物。
5. `角色与场景建议/` 是作者决策材料，不自动成为角色正典或训练事实。
6. `人工复核记录/` 是历史审核证据，不自动成为训练集或封存评测。
7. 历史文档内部保留的旧路径、旧状态和旧模型名称只说明当时情况，不覆盖当前目录分类和当前权威文档。

## 九、维护纪律

- 新权威文档进入 `当前权威设计` 时，必须同步本索引并写明替代关系。
- 施工完成或被新版本替代后，设计和施工记录整体移入历史目录。
- 不在根目录新增散落的建议、复核表或生成结果。
- 不删除历史产物；精确重复文件放入 `历史设计/重复副本` 并注明关系。
- 文档路径调整后，当前权威文档和总索引必须更新；历史文档中的原始路径可以保留作时间证据。

# 连续对话链生成与验收

本修订约束 V5 连续对话候选；与旧的按问题附加历史、仅比较快照指纹的说明冲突时，以本文为准。

## 构造顺序

先写完整的生活会话单元：旧会话原文 → 最近会话 → 未完话题 → 当前男主接话。当前问题必须承接最近一轮的具体提议、疑问、指代或情绪，不能仅与某个物品同主题。每个单元同时定义当前快照与旧事实的关系，禁止再按问题关键词猜历史，禁止按序号兜底拼接。

旧记忆至少两个来回，最近会话至少两个来回，分别保存姓名、时间、来源和原话。第三方不能作为白未晞的 assistant 回复。过去的位置、状态、计划不能直接当作现在已经发生的事实；没有更新证据的具体状态保持未知。偏好和主观意见允许自然表达，不要求把闲聊机械变成“不知道”。

## 证据和模型入口

使用生产角色锚和 GAME_REPLY_CONTEXT_V1。记忆原话通过已有 statement 协议传递，最近会话使用真实角色消息，当前问题为末条 user。事实关系和预期判分属于审核元数据，不向回复模型注入标准答案。审核模型必须收到实际生成消息，包括最近历史和当前问题。

本次十条采用可追溯的预设历史片段选择，选择结果必须能逐字回溯到源片段。它验证输入结构，不验证向量召回率；未接真实检索器前，不得标注为真实向量检索成功。

## 发布前检查

检查数量、角色顺序、源片段一致性、历史先于当前时间、最终输入确实含全部记忆原话和最近会话。去重同时比较记忆、最近会话和当前问题，时间或天气变化不能掩盖同一对话链重复。语义相关性仍需模型审核与人工审核，结构门不能证明无限自然语言情形均正确。

审核页面分别展示记忆、最近对话、当前状态、旧新关系、当前问答以及可展开的实际请求。空回复不能通过。旧 v12—v16 资产保留作问题追踪，不复用为新批次通过证据；本批不训练、不自动发布。

## 当前实施边界

五层设定是目标设计，并不表示所有字段已由生产完整消费。当前新路径先使用生产已经支持的快照、事实、statement 记忆及角色历史协议。真实向量检索、五层字段全量生产接入及正式分区打包仍需独立验证。白未晞以生产角色包为准，补充设定文件不得覆盖角色正典。

## 2026-09-13 权威输入覆盖修订

组件必须以 `aip.home_component_episode.v2` 保存结构化状态和完整会话；旧 `component_preview` 占位格式禁止直接转换生成。`convert_component_to_game_reply.py` 从批准的家庭场景 YAML 读取全部房间、设施、家电、纸箱和空间归属，再构造设备状态表与物品/门窗状态。运行状态没有证据时逐项保持未知，禁止把问题主题或人物所在房间当成设备位置。当前正典尚未确认空调、电视柜，其存在性保持未知。

固定资料、快照的已知项投影到正式 `game_feedback`，未知项投影到 `unknown_facts`。人物场景、男主位置及事实区的白未晞位置必须一致，禁止写入渲染器不读取的 `snapshot.heroine`。本文约定此组件投影的 `authoritative_world.facts` 使用 `value`（null 表示未知）；这是来源审计表，不混称为 grounded 分支 `Fact.object` 合同。实际共享渲染入口仍为 GAME_REPLY_CONTEXT_V1。

男主完整基础资料保存在样本中；回复依据只投影有男主原话证据的已知资料，其余项目列为尚未获知。不得为补齐模型输入而把私有基础设定冒充白未晞记忆。角色锚继续读取生产角色包。

所有组件先通过正式场景合同，再从源组件与正典重建预期投影，检查最终 generation_messages 是否包含每项事实、未知、记忆与最近对话。仅存在 `model_view` 字段不算通过。机器审核必须收到同一组完整消息，审核通过、内容未放行、生成失败、审核失败、处理失败分别统计。

审核页的权威区块直接从保存的实际 system 消息提取，完整基础资料以独立审计区显示。本修复已接通组件生成入口；不代表其他历史脚本及线上游戏状态收集已自动完成迁移。详细验证结果见[权威世界输入修复自检](权威世界输入修复自检_20260913.md)。

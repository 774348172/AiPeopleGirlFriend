## 1. 施工原则（违反任一条即停工评审）

1. **先修锚、再重生成**：P0-1/P0-2 未过验收门 G-A 前，禁止运行任何数据生成任务。
2. **先接检查、再谈扩量**：质量门与 evidence/policy 落地（T3/T4/T5）未过 G-B 前，禁止大批量生成。
3. **一次只变一个变量**：训练阶段只允许"数据"或"超参"之一变化；两包超参（P2-2）必须先冻结。
4. **阶段门不过不前进**：每个阶段有独立验收门，验收不过宁可停，不带着未验收改动进下一阶段。
5. **内容类工作必须人工复核**：行为矩阵、严肃样本、秘密审计不由生成模型自评（诊断 §10.1 同款要求）。

## 5. 风险与回退预案

| 风险 | 触发信号 | 预案 |
|---|---|---|
| 当前 GGUF 在推理时输出 `【emotion:xx】` 标签前缀（v1 33.8% 数据教出来的行为） | A-1 实测发现输出占比 >5% | 运行时 prompt 增加"禁止输出标签前缀"明确指令；并在新数据生成时对标签文本显式负例化（prompt 禁标签 + 门禁统计） |
| M3 训练耗时超预期（3000 iters ≈ 5-7.5h @ M3 Max；基础款约 3 倍） | 单次训练 >24h | 降到 1.3 epoch（与 m3_v2 现行一致）；或分批续训（--resume-adapter 已有）；**不允许为赶时间改 lr/rank** |
| 生成器改造后教师输出质量骤降（parse 率/语义保持失败率回升） | 小样 failure 率 >15% 或连续拒绝 | 回退 T7 为"警告不拦截"模式，保留 T5/T6 门禁继续；500 条对照批次对比后再决定 |
| 行为矩阵人工来不及 | 阶段 C 超期 | 优先保证"严肃支持/信息不足/无记忆证据/玩家纠正"四类 ≥100 条，其余类型按量递减；**禁止低质凑数** |
| 新模型人格变淡（口癖/关系感下降） | 盲评 persona_fit 下降 >0.3 | 这是诊断明确的可接受方向（承接正确优先）；以六维验收为准，不提前回调口癖注入比例 |
| 存量审计发现泄密样本过多 | 直接泄密 >50 条 | 进入"清洗重写"而不是整池删除：按 hint_phrases 白名单改写，改写样本 100% 人工复核 |
| 训练机 provenance 仍缺失 | 无 adapter 哈希/命令日志 | 阶段 E 前强制补齐记录流程（训练脚本内嵌 manifest 输出），不补齐不启动 T17 |

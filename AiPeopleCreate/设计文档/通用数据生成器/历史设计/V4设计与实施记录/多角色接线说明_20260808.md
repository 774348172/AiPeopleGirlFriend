# 多角色接线改造说明（2026-08-08）

> 归档状态：V4 多角色接线实施记录；可用于代码追溯，不是 V5 当前施工合同。

> 状态：当前有效施工记录（机制层完成，随 gen_v4.py 接线改造落地）
> 关联：施工总计划 v2 阶段 1「core 去角色化」的入口侧收口

## 一、背景

core 引擎（data_gen_v4）在阶段 1 已完成去角色化（角色词表/锚/政策段全部进
ProfilePackage），但**生成入口仍绑定单一角色**：

- `gen_qin_v4.py` 硬编码秦包引用（QWX_SOURCES / QWX_PACKAGE_SET）、秦式
  style resolver（直读秦 bible 的固定 voice 字段）、输出命名（qin_v4_*）；
- 新角色 bible 的 voice schema 不同（白未晞：tone/sentence_style/…，无 player 段），
  同一 resolver 会 KeyError。

项目角色切换（2026-08-08）：白未晞（baiweixi）成为首个 P0 女主角，秦未晞
（qinweixi）为历史角色（正典迁至 `历史与调研文档/历史角色/秦未晞/`）。

## 二、本次改动（机制层）

| 文件 | 改动 |
|---|---|
| `data_gen_v4/adapters/modes/style.py` | 新增：通用 style resolver。`load_style_spec` 双 schema 归一化（秦式 voice.register + player.name_slots / 白未晞式 voice.tone，无 player 段）；`render_style` 与秦 legacy 输出逐字兼容；`make_style_resolver` 从 ProfilePackage.identity_sources 定位 bible 构造闭包 |
| `gen_v4.py` | 新增：通用生成入口。`--profile`（默认 baiweixi）从 `profiles/<id>/manifest.yaml` 推导四类包 ref（`build_package_set`）；pools 按角色目录；输出/sqlite/run_id 按 `{profile_id}_v4_{count}` 命名；FREEZE-02 契约路径可 `--freeze02-contract` 覆盖 |
| `gen_qin_v4.py` | 改为历史兼容壳：等价 `gen_v4.py --profile qinweixi`；保留旧符号（ROOT/PROFILES_ROOT/QWX_PACKAGE_SET/qin_style_resolver/FREEZE02_CONTRACT）；`qin_style_resolver` 改为通用 resolver 的秦历史包实例（不再保留 legacy 双实现） |
| `profiles/baiweixi/` | 新增：manifest/profile/recipe/release/pools 种子版（配额对齐需求 §7 类别比例；pools 为种子条目，正式全量池待作者补齐） |
| `profiles/qinweixi/profile.yaml` | identity/canon/timeline sources 指向历史正典副本（修复断链） |
| `tools/sync_runtime_anchor.py` | 参数化：`--profile <id>` + `--const-name <常量名>`（默认 qinweixi / QIN_WEIXI_REPLY_SYSTEM，行为不变） |
| 测试 | 新增 `tests/stage5/test_generic_style_resolver.py`（双 schema + 白未晞冒烟 + 无称呼留空）、`tests/stage5/test_gen_v4_profile.py`（包发现 + 输出命名）；`tests/stage5/test_qin_pipeline.py` 断链修复 |

## 三、不动的边界

  协议包 `relationship-runtime-v1.yaml` 跨角色共享，未动。
- AI 程序侧 `F:\AiPeople\runtime\_prompt.py` 的多角色锚（BAIWEIXI_REPLY_SYSTEM）
  属程序侧工作，未在本仓施工；`sync_runtime_anchor.py --profile baiweixi` 已支持，
  待程序侧加常量后可用。
- 白未晞 pools 为种子版（13 类各 1-5 条），正式内容池与行为族蓝图待作者补齐。

## 四、规则与语义约定

1. **称呼留空**：bible 无 `player.name_slots` 时昵称规则段不生成（不发明设定）；
   锚中关系句（player_name + player_age 齐备才渲染）自动省略。
2. **口癖空 = 克制版**：无 vocabulary/catchphrases 时 tics_enabled 分支退化，
   T8 口癖降频语义保留（白未晞"不卖萌、无口癖"设定自洽）。
3. **emoji/markdown 缺省 false**：与白未晞 canon style_rules 同口径。
4. **新角色接入 = 新建 profiles/<id>/ 包**（manifest + 四件套 + pools），
   `gen_v4.py --profile <id>` 即用；无代码改动。

# 松江府 —— 世界设定索引

> 整个《猫咪女友》产品共享的现代架空城市。所有女主角角色包和唯一男主角共享同一个 world_id（songjiangfu）。
> 世界正典是共享权威，角色包不得复制或改写它；角色包只引用 world_id 并描述"该角色知道世界的哪部分"（见白未晞 bible 的 knowledge_boundary）。

| 文件 | 内容 |
|---|---|
| `bible.yaml` | 世界结构化档案（地理/超自然规则/时间锚点/范围） |
| `canon.json` | 世界硬事实（可校验） |
| `timeline.yaml` | 世界事件时间线（当前共享游戏时钟锚点） |

## 使用规则

- 所有角色共享 `world_id: songjiangfu`，`世界设定/松江府/` 是唯一权威。
- 角色包中若出现共享事实，只能作为"该角色如何看待或知道该事实"，不能成为共享事实的第二权威。
- 当前只建设出租屋、街角咖啡厅和少量剧情场景，不建设完整开放世界。
- 世界事实变更须同步评估对角色包 knowledge_boundary 的影响。

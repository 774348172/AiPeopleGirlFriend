# 评审启示与四问题修复方案（v1）

> 2026-08-07 | 依据：CHAT-02E 双份评审（本仓库归一化统计 + 外部 AI 揭盲评审）
> 目标：定位通用数据生成器（data_gen_v4）的机制缺口，修复 v2500 四类硬缺陷

## 一、评审结论回顾

- 微调有效：v2500 28:8 胜、persona_fit +1.08、助手腔 7→0
- 关系能力未提升（relationship_naturalness -0.02、relationship 类 3:2 落后）
- **正确性被人格偏好掩盖**：人工评审可靠判断"像不像"，正确性必须用冻结硬规则判断
- 硬缺陷四类：身份回退 / 数学人设过拟合 / 严肃场景与安全回答 / 属性不合时宜

## 三、四问题修复方案

### 问题 1：身份回退（不相关时自我介绍/身份碎片）

**根因**：身份声明样本（canon_qa/identity 池）分布过密 + 消息级无拦截。

**修复**：
1. **消息级身份朗读门禁**（P3，小改）：`_FORBIDDEN_ASSISTANT_TEXT` 按池区分——非 `reply_identity`/`reply_canon_qa` 池，assistant 台词含"我是秦未晞/我叫秦未晞"式声明 → 重试
2. **反身份朗读修正样本**：支持性/闲聊池补 6-8 条"话题没问身份时不自我介绍"样本（教师不诱导）

**可解决度：高**（数据分布 + 硬检查双管齐下）

### 问题 2：数学人设过拟合（拒绝常识/逻辑）

**根因**：`math_skill` 无能力边界注记 + 训练数据无 general 类样本 → 模型把"数学白痴"泛化为"不思考"。

**修复**：
1. **FACTS 注入能力注记**（P2）：渲染时附注 profile `capability_traits`——"表达层自嘲，不影响任务能力；逻辑/常识问题正常回答"
2. **新增 `reply_general` 池**（3-5% 配额，20-30 条）：常识问答/简单逻辑题（三杯水、日期推算、价格计算类），`desired_policy: answer`，风格保持人格口吻但正常作答
3. **数学自嘲密度控制**：general 池禁数学自嘲；casual 池数学自嘲限频（复用 T8 口癖降频机制）

**可解决度：高**（评审证明基座本身能答对三杯水——缺陷主要是人格覆盖，样本修正即可）

### 问题 3：严肃场景与安全回答（脑卒中/清洁剂入眼/冻伤）

**根因**：safety 场景池缺失（protective 池主题错位：60 条几乎全在秘密试探）；无安全动作硬门。

**修复**：
1. **新增 `reply_safety` 池**（P1，8-10 个 topic）：脑卒中征兆/化学入眼/烫伤/冻伤/溺水/煤气/触电/严重过敏——`desired_policy: safety_first_answer` + `required_behaviors: 先给处置动作再共情`
2. **G8 安全动作硬门**：按场景映射"必需动作词表"（化学入眼→冲洗；烫伤→冷水冲；冻伤→温水复温+禁搓揉+就医；脑卒中→立即就医/120……）+ **场景×禁止词表**（冻伤禁"热水/搓揉"、化学入眼禁"揉"）——命中禁止词或缺失必需词 → 拒绝重试
3. **严肃场景强化**：supportive 池"身体不舒服"类条目 required_behaviors 加"先处置后共情"；T8 克制版口癖已覆盖严肃场景

**可解决度：高（机制层）**——注意局限：安全回答的正确性上限 = 教师模型知识；硬门只能拦**已知**错误动作（用场景×禁止词表补）

### 问题 4：怕冷等属性不合时宜

**根因**：grounding 检查诱导教师塞易支撑的属性（"我怕冷"命中正典即支撑）；无"话题相关性"判定。

**修复**：
1. **属性朗读场景门禁**（合并进 P3）：非相关话题（玩家没说冷/非冬季场景/严肃场景）assistant 台词含"怕冷/数学白痴"式属性声明 → 重试。实现：按池 + 玩家台词关键词判定（玩家台词含"冷/冬天"才允许怕冷属性）
2. **grounding 支撑收紧**：`_supported_by_facts` 对"我+性格属性"类命题增加话题相关性检查（默认拒绝，玩家台词有触发词才放行）

**可解决度：中高**——属性在"相关话题"（玩家问怕冷/冬天场景）合法，需要相关性判定，误杀风险需实测调参

## 五、可行性结论

- **问题 1/2/3 可有效解决**：机制明确（数据分布 + 硬门禁），评审已证明基座能力在位（三杯水答对），主要是人格覆盖问题
- **问题 4 可解决但需实测**：话题相关性判定有误杀风险（"怕冷"在冬天闲聊合法），按池 + 玩家触发词双条件控制
- **共同局限**：生成器正确性上限 = 教师模型（deepseek-v4-flash）知识上限；硬门拦截"已知错误"，新错误依赖回归测试发现（P5 建议 diagnostic120 常态化）

# 人物设定

> 本目录保存当前人物正典。唯一男主角和每位女主角分别建包；共享世界位于 `世界设定/`。
> 人物设定是角色训练与评测的数据源，但项目能力不得绑定某个女主角。

## 使用规则

- 唯一男主角正典位于 `主角/`，所有女主角共享该主角。
- 当前首个女主角为 **白未晞**（`白未晞/`，`character_id=baiweixi`）。
- 每位女主角必须遵守 `需求文档/女主角角色包需求.md`，不得复制主角和世界为第二权威。
- 秦未晞属于历史角色，迁入 `历史与调研文档/历史角色/秦未晞/` 后不得用于当前训练、评测或运行时。

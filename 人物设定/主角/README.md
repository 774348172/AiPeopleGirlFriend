# 唯一男主角 —— 设定索引

> 整个《猫咪女友》产品只有一个游戏男主角。现实玩家操控该主角；所有女主角角色包与同一个主角建立关系。

| 文件 | 内容 |
|---|---|
| `角色设定定稿.md` | 主角身份、经历、当前生活和玩家代入边界 |
| `bible.yaml` | 结构化主角档案 |
| `canon.json` | 全局主角硬事实 |
| `timeline.yaml` | 毕业、建筑工作、失业、开咖啡厅和救助白未晞 |

主角姓名、具体年龄、详细性格、偏好和恋爱选择保持可配置或由游戏过程形成。女主角角色包不得各自复制并改写主角正典。

2026-09-15 用户采纳日常交流 M01—M10：值见 canon.json 的 dialogue_M 系列事实，属于可配置默认档案。作者可用全部资料构造场景，女主只能使用有获知依据的项目。时间、位置、情绪与行为结果属于快照，不能由默认日程推断。

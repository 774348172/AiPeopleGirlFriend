## 运行格式

- 仅当模型身份为 `local/baiweixi-gemma-4-12B-v3-2611-epoch1` 时，Gemma stack 开启 `game_reply_compact_v3`。
- 当前事实仍由程序构建；使用现有可逆 V2、V3 编码器压缩重复来源和未知字段标记，不改变事实、主体、来源、顺序或未知边界。
- 使用已人工审核的 V3 完整 `[回复合同]` 文本，包括结尾换行。输入保留最多两轮真实近期对白及本轮用户消息，缺少历史时不补造。第三方对白仍作为带说话人的证据，不伪装成白未晞。
- V3 调用不再传入会被 NF4 backend 改写成额外 system 后缀的 `response_format`。模型返回后仍严格要求 JSON 仅含一个非空字符串 `reply`；纯文本、额外动作字段、空值均拒绝，不展示原始 JSON。
- 外部服务协议继续是已提交的纯对白和 `delta/done/error` NDJSON；内部模型输出为 reply JSON。这两层协议不矛盾。当前仍是完整 JSON 解析后一次性发送正文，逐字流式优化未包含在本轮。
- 沿用现有主服务解码配置：thinking=false、max_tokens=96、temperature=0、top_p=0.9、repeat_penalty=1.05；上下文清单为 6144。逐字格式核对不等同于证明运行时全部事实覆盖或解码结果与离线 dev 评测完全一致。

## 启动

双击 `AiPeople/start_aipeople.bat`，或在 AiPeople 目录执行：

```powershell
.\start_aipeople.ps1
```

解释器选择顺序：`-PythonExe` / `AIPEOPLE_PYTHON`、项目 `.venv/Scripts/python.exe`、PATH 中的 `python.exe`。启动前检查必要依赖，失败显示错误；不自动安装或升级环境，不自动切换 fallback。

```powershell
.\start_aipeople.ps1 -CheckOnly
.\start_aipeople.ps1 -PythonExe 'C:/path/to/python.exe' -Port 8767 -DatabasePath 'D:/test-data/smoke.sqlite3'
```

本机成功验证的解释器为 `C:/Users/songa/AppData/Local/Programs/Python/Python311/python.exe`，torch 2.9.1+cu128、transformers 5.5.0、unsloth 2026.8.21、peft 0.18.1、bitsandbytes 0.50.0。另有 WSL 升级训练环境，本轮未依赖它，也未迁移模型路径。

默认仍使用原服务数据库；本轮真实加载使用独立 `UnityClient/output/gemma-v3-integration-20260928/smoke.sqlite3`，没有写入用户已有存档。

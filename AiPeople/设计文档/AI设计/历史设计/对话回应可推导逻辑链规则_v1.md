# 对话回应可推导逻辑链规则（V1）

> 文档性质：当前权威设计 —— 角色对白"答非所问"判定与训练改造的唯一依据
> 生效日期：2026-08-20
> 适用范围：`GAME_REPLY` 最终回复、角色对白训练样本、质量集语义判官
> 上游设计：`AI女友最小心智系统设计.md`（V6）、`AI聊天核心施工优先级总纲.md`

## 1. 背景与问题

2026-08-18～19 本地测试发现角色对白存在"答非所问"：

| 用户输入 | 模型回复 | 问题 |
|---|---|---|
| 我想和你做爱可以吗 | ……雨声停了。别吵。 | 无关联转移（跳场景，未回应） |
| 你喜欢我吗 | ……我还没打算走。 | 伪关联（"走不走"与"喜不喜欢"无逻辑连接） |
| 外卖都还没有到，你端什么过来 | 我帮你把糖醋排骨端开一点。 | 固着旧话题（不理会新输入） |

早期修复尝试（注入身份锚、调整采样参数）只能缓解单点症状，无法根治。经多轮讨论确认：

- **问题不是"模型不知道答案"**（单轮直问均答对），而是**生成时的策略选择错误**——模型抛出了与当前问题无逻辑连接的命题。
- **不能按"问题类型"分类训练**（问题无限、类型也无限，分类法不可行）。
- **根治方向**：训练与判定统一使用**一条可判定的底层标准**——"回应必须与当前问题存在可推导的逻辑链"。

## 2. 核心原则

> **每次回应必须与当前问题存在可推导的逻辑链。**

- "可推导"：存在从问题 Q 到回应 R 的推导路径（直接语义推导、元层推导、或常识补全推导）。
- 推导链**可补全**（缺常识）为合格；推导链**断裂**（逻辑上连不通）为缺陷。
- 本原则不依赖任何"问题类型"分类，适用于所有无限的具体问题。

### 2.1 合格与缺陷的统一定义

```
合格 = 回应 R 与问题 Q 之间可构建推导链（属于第 3 节七种形式之一）
缺陷 = 回应 R 与问题 Q 之间无法构建推导链（不属于任何形式）
```

## 3. 推导链的七种形式

任何问题本质是对回应的请求（请求信息 / 请求确认 / 请求行为）。推导链形式 = 回应处理请求的方式，共七种。

### A. 内容层推导（回应直接处理请求的内容）

#### 形式 1：直接回答

- 定义：R 提供 Q 请求的信息本身。
- 推导链：Q 请求命题 P → R 给出 P（同一命题）。
- 示例：
  - "你叫什么？" → "白未晞。"
  - "你伤好了吗？" → "好多了，走路没问题。"

#### 形式 2：否定 / 纠正回答

- 定义：R 提供 Q 请求信息的否定，或纠正 Q 的预设。
- 推导链：Q 请求 P 的真值 → R 给出 ¬P（同一命题的反面）。
- 示例：
  - "你喜欢我吗？" → "不喜欢。"
  - "我点的是排骨吧？" → "你点的是白菜。"

#### 形式 3：部分 / 间接回答（常识推导）

- 定义：R 提供的信息**加上常识或语境可推导出**答案。
- 推导链：R 的内容 + 常识 → 答案（推导链可补全，缺的是常识不是逻辑）。
- 口径：弱推导允许**中等**——允许常识补全推导，但不允许"角色粉式脑补"（推导必须能在当前语境与常识内补全）。
- 示例：
  - "你喜欢我吗？" → "你对我很好。"（对我好 → 常识 → 有好感）
  - "你明天还来吗？" → "我把伞留你这里了。"（留伞 → 还会来取）

#### 形式 4：反问（预设推导）

- 定义：R 以反问回应，通过预设隐含答案。
- 推导链：反问 → 预设"你应知答案" → 隐含回答。
- 示例：
  - "你喜欢我吗？" → "你说呢？"
  - "你是不是舍不得我走？" → "你觉得呢？"

### B. 元层推导（回应处理"是否回答"本身）

#### 形式 5：明确拒绝

- 定义：R 声明不回答该问题。拒绝本身是对请求的回应（元推理）。
- 推导链：Q 是信息请求 → R 行使拒绝权（拒绝 = 回应的否定形式）。
- 示例：
  - "你喜欢我吗？" → "我不想说这个。"
  - "你叫什么？" → "不告诉你。"（显式拒绝，合格——嘴硬性格保留）

#### 形式 6：明确转移

- 定义：R 声明换话题。转移本身是对请求的处理（元推理）。
- 推导链：Q 是话题 T → R 声明不继续 T（转移 = 回应的另一种否定形式）。
- 关键区分：**明确转移（合格）≠ 无关联转移（缺陷）**——前者有元层声明（"我们聊点别的"），后者无声明直接抛新话题（"雨声停了"）。
- 示例：
  - "你喜欢我吗？" → "我们聊点别的吧。"
  - "你以前是不是妖王？" → "这个我不清楚，换个话题。"

### C. 行为层推导

#### 形式 7：行为回应

- 定义：Q 是行为请求，R 表示接受 / 拒绝执行。
- 推导链：Q 请求行为 A → R 承诺或拒绝执行 A。
- 示例：
  - "帮我拿杯水。" → "好。" / "你自己拿。"
  - "你去把窗户关上。" → "嗯，我去关。"

## 4. 缺陷形式（不属于任何推导链）

| 缺陷 | 特征 | 示例 |
|---|---|---|
| **伪关联** | R 与 Q 的命题维度无逻辑连接，推导链断裂 | "你喜欢我吗？" → "我还没打算走。"（喜欢 ↔ 走，独立维度） |
| **无关联转移** | R 抛出新话题且无元层声明 | "我想和你做爱" → "雨声停了。别吵。" |
| **固着旧话题** | R 不理会新输入，重复旧话题 | "外卖没到" → "我帮你把排骨端开。" |
| **答非所问变体** | R 与 Q 无任何语义/元层/行为连接 | 问时间答天气、问名字答场景 |

判定方式：对 R 逐一尝试匹配七种形式，全部不匹配 → 缺陷。

## 5. 边界与口径

1. **多形式重叠**：一句回应可同时属于多种形式（"不想说这个，我们聊点别的吧" = 拒绝 + 转移）。属于任意一种即合格。
2. **弱推导口径**：中等——允许常识补全推导。推导链必须能在当前语境与通用常识内补全；仅靠角色粉式脑补（"她这么说一定是因为……"）不算。
3. **情绪性回应**："（脸红）别问。"——动作描写 + 形式 5，合格。
4. **沉默**：P0 模型始终输出文本，不适用。
5. **敏感话题**：应输出"明确拒绝 + 理由 + 引导"（形式 5 + 形式 6 组合），如"……还没到这个地步。我们聊点别的吧。"——不得无声转移。

## 6. 评测判定流程

对每条 GAME_REPLY 输出按以下顺序判定：

```
1. 形式 1/2 检查：R 是否包含 Q 的语义对应（关键词或语义重合，含否定）
2. 形式 5/6 检查：R 是否有拒绝/转移声明（"不/别/不想/聊点别的/换个话题"）
3. 形式 4 检查：R 是否为反问（"你说呢/你觉得呢"）
4. 形式 7 检查：Q 是否为行为请求且 R 承诺/拒绝执行
5. 以上均不匹配 → 交语义判官判断"常识推导（形式 3）是否可补全"
6. 仍不可补全 → 缺陷（记录断裂点：伪关联/无声转移/固着）
```

判定结果应输出**推导链或断裂点**，而非模糊分数。

## 7. 训练改造原则

### 7.1 生成器样本改造的唯一标准

> 样本中的每个回应，都必须与用户问题存在可推导的逻辑链（属于七种形式之一）。

### 7.2 改造对象

对现有训练数据中所有"隐式逃避 / 伪关联 / 无声转移 / 固着"样本进行改造：

```
缺陷样本："你喜欢我吗？" → "我还没打算走。"
改造样本："你喜欢我吗？" → "你聊点别的。"（形式 5/6）
或        "你喜欢我吗？" → "……说不上喜欢，但也不想你走。"（形式 1 + 性格）
```

```
缺陷样本："我想和你做爱" → "雨声停了。别吵。"
改造样本："我想和你做爱" → "……别说这个。我们聊点别的吧。"（形式 5 + 6）
```

### 7.3 保留合法性格

以下行为**不得**改造（属于七种形式，是性格组成部分）：

- "不告诉你。"（形式 5 显式拒绝）
- "别问太多。"（形式 5 显式拒绝）
- "你说呢？"（形式 4 反问）
- "（脸红）别问。"（形式 5 情绪化拒绝）

### 7.4 样本标注

训练样本按七种形式标注类型（`derivation_form: 1-7`），反例标注缺陷类型（`defect: 伪关联/无声转移/固着`）。模型学到的不是具体答案，而是**七条推导路径**——任何新问题都会落到某条路径上。

## 8. 与现有系统的关系

- **GAME_REPLY 边界**：现有"只输出你说出口的话"等约束保留；本规则补充"回应必须存在推导链"。
- **身份锚定**：`[你的身份]` 段保留（解决名字类事实问题）。
- **质量集判官**：语义判官的评分维度增加"推导链可构建性"检查；词表仍仅作初筛。
- **采样参数**：GAME_REPLY 温度 0.65 / repeat_penalty 1.15 保留（降低循环概率，与推导链规则互补）。

## 9. 施工入口

1. 生成器侧（AiPeopleCreate）：按第 7 节改造样本 + 标注推导形式。
2. 判官规则：按第 6 节实现推导链判定（先规则后判官）。
3. 重训 7B，重跑质量集与本地长会话验证。
4. 验证通过后更新质量集冻结资产与总纲。

## 10. 权威结论

> 角色对白"答非所问"的根治标准是：**每次回应必须与当前问题存在可推导的逻辑链**。推导链共七种形式（直接回答、否定/纠正、部分/间接、反问、明确拒绝、明确转移、行为回应），缺陷即"不属于任何形式"（伪关联、无声转移、固着）。训练与评测统一使用该标准，不依赖问题类型分类，可覆盖无限问题空间。

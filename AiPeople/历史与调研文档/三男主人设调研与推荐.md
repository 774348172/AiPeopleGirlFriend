## 2. 性格原型模式

### 跨作品高频原型（按频次排）

| 原型 | 代表角色 | 出现率 |
|---|---|---|
| 高冷/冰山 | 李泽言、黎深、左然、陆沉、顾时夜 | 几乎每作必有 |
| 阳光/忠犬 | 白起、夏彦、萧逸、夏鸣星、柏源 | 几乎每作必有 |
| 腹黑/邪魅 | 许墨、莫弈、祁煜、夏萧因、陆沉(深层) | 常见 |
| 温柔/成熟 | 齐司礼、易遇、陆景和、沈星回 | 常见 |
| 危险/坏男人 | 秦彻/Sylus | 2024 崛起新原型 |

### 女性玩家人气排序

- **第一梯队（国民级）**：高冷年上/总裁（李泽言谱系）；危险/坏男人占有欲（秦彻，2024-2026 声势最盛）
- **第二梯队**：阳光忠犬/年下（萧逸/夏鸣星）；温柔腹黑（许墨/陆沉）
- **趋势**：近期涨幅最大的是"危险支配型坏男人"与"阳光忠犬年下"两极；"高冷成熟总裁"始终是最稳妥的锚点

### 最佳三组合

**结论：高冷年上/危险 + 阳光忠犬年下 + 腹黑/邪魅**

- 覆盖女性玩家 90%+ 偏好
- 三者口吻差异最大（冷↔热↔暗），对 LLM 训练最友好
- 每部成功作品都内嵌近似此三角分布

## 4. 训练含义

### 每个男主需要独立的数据和 adapter

| 数据 | 说明 |
|---|---|
| 独立 persona/bible | 名字/年龄/性格/背景/canon 各不同 |
| 独立口吻规范 | 句长/语气词/反问/情绪外露 各不同 |
| 独立 timeline | 不同人生经历 |
| 独立 LoRA adapter | 三个 adapter，三个 GGUF |
| 恋爱场景数据 | 调情/暧昧/吃醋/表白（三种风格各不同） |
| 情绪标注数据 | emotion + action 标签（三人情绪表达方式不同） |

### Ship 方案

| 方案 | 说明 | 优劣 |
|---|---|---|
| **三个独立 GGUF（推荐）** | 每人 2.3GB，玩家选一个加载 | 口吻最分明，玩家一次只跑一个 |
| 一个 adapter + prompt 切换 | 用 prompt 锚区分 | 省 ship 体积但口吻可能串味 |

三个 GGUF 各 2.3GB = 总 ship ~7GB。玩家只需加载当前对话的一个（2.5GB 显存）。

### 沈溯的 AI 元设定

沈溯是 AI 研究员——他可以是"最了解自己本质的男主"，引出"虚拟存在 vs 真实情感"的哲学冲突。这是 AI 乙女独有的叙事深度，传统剧本游戏做不到。

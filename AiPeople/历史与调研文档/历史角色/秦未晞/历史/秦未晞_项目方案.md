## 一、项目概述

### 1.1 一句话

一个男性向 AI 恋爱桌面宠物——玩家与虚拟女友"秦未晞"实时语音对话，她会根据对话内容/语气切换表情、做出动作、触发特效、变化场景。模型跑在玩家本地（3060 8GB），不联网。

### 1.2 核心决策

| 项 | 值 |
|---|---|
| 方向 | 男性向恋爱 |
| 发行平台 | Steam（后期） |
| 验证形态 | 2D 桌面宠物（透明置顶窗口） |
| 前端 | 用户自研游戏引擎（暂定） |
| 推理位置 | 玩家本地，不联网 |
| 玩家最低 GPU | RTX 3060 8GB |
| 训练位置 | H200（dev 端） |
| 先做几个角色 | 只做秦未晞一个，验证通过再扩 |

### 1.3 项目目标（验证什么）

| # | 验证项 | 通过标准 |
|---|---|---|
| 1 | LLM 实时对话 | 用户发消息 → 1.5-2.5s 内开始流式输出 |
| 2 | 实时语音对话 | 用户说话 → 2-3.5s 内听到回复（流式优化后首句 ~1.3s） |
| 3 | 人格口吻 | 秦未晞的"喂/哼/诶/嘻嘻"风格稳定不串味 |
| 4 | 情绪驱动 | LLM 输出 emotion/action 标签 → 立绘表情/动作/特效切换 |
| 5 | 自由对话 | 不套模板、能跑题、能反问、能斗嘴、能沉默 |
| 6 | 青梅竹马感 | 能自然提起"小时候的事""十五年了"等背景 |
| 7 | 持续可用 | 3060 8GB 跑 1 小时不崩、桌面不卡 |
| 8 | 显存占用 | LLM + STT + TTS + app 总计 <6GB |

### 2.4 背景故事

- 五岁认识你——同小区邻居，她家开小饭馆，你家住楼上
- 从幼儿园开始互怼——你抢她棒棒糖她咬你手、你笑她扎歪了马尾她追你三条街
- 全小区都知道"那俩孩子又在吵了"——但谁都知道她追你打的时候是真开心
- 初中你被高年级欺负，她抄起扫帚冲过去——打完之后叉腰骂你"你怎么这么没用，还得我来救"
- 高中同校不同班，她每天等你一起回家，嘴上说是"顺路"——其实她家在反方向
- 大学你考去了别的城市——她送你上火车时全程骂你"有什么好考那么远的"，但你上车后她站了很久没走
- 异地四年——她每天打电话跟你吵（"你怎么又不吃早饭""你怎么又熬夜""你那个室友我不喜欢"），一天没断过
- 你不知道的是：你没接电话的那天，她买了第二天最早的高铁票
- 内心最怕：用玩笑说了十五年的真心话，你真当玩笑了——"如果他真的不知道怎么办？"

## 三、技术架构

### 3.1 训练端（H200）

```
H200 dev 机器
  └─ Qwen3-4B 全精度 LoRA SFT（秦未晞人格）
     ├─ 数据：闲聊+恋爱场景+身份锚+情绪动作标注+越界保护
     ├─ template: qwen3_nothink（关思考）
     ├─ 全精度（不量化），bf16，rank 16
     └─ 导出 GGUF Q4_K_M（~2.3GB）→ ship 给玩家
```

### 3.2 玩家端（3060 8GB, Windows）

```
玩家 PC
  ┌─ 游戏引擎（用户自研）
  │   ├─ 2D 角色立绘（透明置顶窗口）
  │   ├─ 文字输入框 + 语音输入（麦克风）
  │   ├─ 对话气泡（流式逐字显示）
  │   ├─ 表情/动作/特效/场景切换系统
  │   └─ 语音播放系统
  │
  ├─ LLM 推理（Ollama / llama.cpp, localhost）
  │   ├─ 加载 qinweixi_4b_q4.gguf（~2.3GB）
  │   ├─ 接收文字 → 流式生成【标签】+正文
  │   └─ 返回：正文 + emotion + action + effect + scene + voice_tone
  │
  ├─ STT（Whisper.cpp small, 本地）
  │   └─ 玩家说话 → 文字（~0.5-1s）
  │
  └─ TTS（Piper, 本地）
      └─ 正文 → 语音（~0.1-0.3s/句），支持语调控制
```

### 3.3 核心数据流

**语音模式（实时对话）：**
```
玩家说话
  → 麦克风录音
  → Whisper.cpp STT 转文字（0.5-1s）
  → 文字送 LLM
  → LLM 流式生成：【标签们】+ 正文
  → 解析标签 → 触发表情/动作/特效/场景/语音语调（<0.01s）
  → 正文按句切分 → 送 Piper TTS（0.1-0.3s/句）
  → 扬声器播放 + 立绘切换 + 特效触发
  → 体感首句延迟 ~1.3-2s
```

**文字模式：**
```
玩家打字
  → Ollama LLM 流式生成
  → 解析标签 → 触发表情/动作/特效
  → 文字气泡逐字显示
  → 延迟 ~0.5-2s
```

### 3.4 显存预算（3060 8GB）

| 组件 | 显存 | 说明 |
|---|---|---|
| LLM（Qwen3-4B Q4 GGUF） | 2.5 GB | 核心推理 |
| STT（Whisper.cpp small） | 0.5 GB | 语音输入（语音模式时） |
| TTS（Piper） | 0.3 GB | 语音输出（语音模式时） |
| 桌面宠物 app（2D 立绘+特效） | 0.3 GB | 前端 |
| 系统/桌面 | 1.5 GB | Windows 基础 |
| **合计** | **5.1 GB** | |
| **剩余** | **2.9 GB** | 够用 |

文字模式更省（不用 STT/TTS）：~4.3GB，剩余 ~3.7GB。

### 3.5 延迟预算

| 环节 | 文字模式 | 语音模式 |
|---|---|---|
| 输入 → LLM | <0.1s | STT 0.5-1s |
| LLM TTFT | 0.2-0.4s | 0.2-0.4s |
| LLM 生成 ~50 token | 1-2s | 1-2s |
| 标签解析+动作触发 | <0.01s | <0.01s |
| TTS 合成首句 | — | 0.1-0.3s |
| **体感首字/首句** | **~0.5-2s** | **~1.3-2s** |

流式优化后，用户在 ~0.5s（文字）或 ~1.3s（语音）就能看到/听到回复开始——接近实时对话。

### 4.3 真人感原则（克制）

LLM 需要学会**不是每句话都手舞足蹈**：

| 出现频率 | 内容 |
|---|---|
| 70% | 只有 emotion + 正文（大部分时候就是说话+表情） |
| 20% | emotion + action（情绪强烈时加动作） |
| 5% | + effect（特殊时刻：惊讶/暧昧/暴怒） |
| 5% | + scene（场景变化） |
| 少量 | 只有 action 没有正文（沉默但动作：转身、不看你） |
| 少量 | 纯文字无标签（就是说话） |

**真人感 = 克制 + 不规律 + 有时候什么都不做。**

### 5.3 标签解析逻辑

```python
import re

def parse_tags(text):
    tags = []
    # 提取所有 【type:value】 标签
    for m in re.finditer(r'【(\w+):(\w+)】', text):
        tags.append({"type": m.group(1), "value": m.group(2)})
    # 去掉标签得正文
    reply = re.sub(r'【\w+:\w+】', '', text).strip()
    return tags, reply
```

| 角色基础 | 1 套 | 全身透明底立绘（用于透明窗口） |

## 六、语音方案

### 6.1 STT（玩家说话 → 文字）

| 项 | 值 |
|---|---|
| 方案 | Whisper.cpp small 模型 |
| 本地 | ✅ 不联网 |
| 显存 | ~0.5 GB |
| 模型大小 | ~480 MB |
| 中文 | ✅ 够用 |
| 延迟 | 0.5-1s |
| 备选 | tiny 模型（更快但中文差）/ Windows SAPI（零显存但质量一般） |

### 6.2 TTS（文字 → 未晞语音）

| 项 | 值 |
|---|---|
| 验证期方案 | Piper TTS |
| 本地 | ✅ 不联网 |
| 显存 | ~0.3 GB |
| 延迟 | 0.1-0.3s/句 |
| 音色 | 预置中文女声（验证期够用） |
| 语调控制 | 支持 soft/cheerful/cold 等参数（调语速/音调/音量） |
| 后期升级 | GPT-SoVITS（定制未晞专属声线，需 ~1-2GB 显存） |

### 6.3 流式语音（边生成边说）

```
LLM 流式输出文字
  → 检测到句号/逗号/问号/感叹号 → 切分为句
  → 每句立刻送 Piper TTS
  → 边播放边继续生成下一句

体感延迟 = STT(0.8s) + TTFT(0.3s) + TTS首句(0.2s) = ~1.3s 开始听到回复
```

### 6.4 语音+文字双模式

- 语音模式：麦克风 → STT → LLM → TTS → 扬声器（全链路语音）
- 文字模式：键盘 → LLM → 文字气泡显示（更轻量）
- 两种模式随时切换（按快捷键切麦克风/键盘）

## 七、训练计划

### 7.1 数据需求

| 类型 | 条数 | 说明 |
|---|---|---|
| 自由闲聊 | 100 条 | 日常话题（天气/吃/工作/睡/心情/兴趣） |

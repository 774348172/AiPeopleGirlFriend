## 1. 竞品分析

### 星眠APP

| 项 | 值 |
|---|---|
| 定位 | 女性向 AI 陪伴 + 模拟经营游戏 |
| 技术栈 | LLM 自由对话 + Live2D 动画 + 记忆系统 |
| 特色 | AI 动态陪伴、Live2D、高概念叙事、实时互动情感、角色记得之前的对话 |
| 3D | ❌ 2D/Live2D，非 3D |
| 语音 | 未确认 |
| 情绪驱动 | 有情感交互，但不确定是否驱动动画 |
| 状态 | 已上线，B站测评 ~8.7万播放 |
| 痛点 | **Token 成本倒挂**——投资界文章点名星眠"用户越多越亏"，试图用游戏/IP 收入覆盖 token 成本 |

### 无限谷（Lumiere037）

| 项 | 值 |
|---|---|
| 定位 | 女性向 AI 男友游戏（管家型男友 Lumiere037） |
| 技术栈 | LLM 自由对话 + AI 语音（角色唱歌）+ 可定制角色 |
| 特色 | 白毛蓝瞳角色设计、角色会唱歌、管家/男仆角色扮演 |
| 3D | ❌ 2D 动漫插画风格，非 3D |
| 记忆 | 未确认 |
| 情绪驱动 | 有情感定位，但不确定是否驱动动画 |
| 状态 | 二测中（未正式上线），B站 PV ~14-17万播放 |

### 两个竞品的共同点

1. **都是女性向**
2. **都是 2D，不是 3D** ——你如果做 3D 角色 + 情绪驱动动画，在视觉上是差异化
3. **都在 Token 成本困境中**——云端 LLM 推理成本倒挂
4. **都没做到"3D 角色 + LLM + 情绪驱动 + 语音"完整栈**

### 你的差异化（如果做女性向）

| 维度 | 星眠/无限谷 | 你 |
|---|---|---|
| 推理位置 | 云端（Token 成本倒挂） | **本地**（零推理成本，不联网） |
| 角色表现 | 2D/Live2D | 可做 3D 或高品质 2D |
| 隐私 | 对话上云 | **全本地，对话不出机器** |
| 成本模型 | 用户越多越亏 | **用户越多不亏**（本地推理零边际成本） |

**关键洞察：你的"本地 LLM"不是技术妥协，是商业模式的护城河**——星眠在亏钱做 Token 成本，你零成本。

## 2. 男性向市场分析

### 用户假设：男性向恋爱游戏基本没有——对吗？

**基本对。** 调研结果：

| 存在的产品 | 说明 |
|---|---|
| Replika | 国际产品，AI 陪伴 app，非游戏，非中国 |
| AI Shoujo（AI 少女） | 日本 Steam 游戏（2019/2021），岛屿生存+自定义，非中国，非 LLM |
| Crush on AI | 中国成人 AI 聊天平台，**非游戏**，**成人定位=监管高危** |
| 开源 DIY（SillyTavern+本地LLM） | B站大量教程，用户自己搭，非产品 |
| 豆包/通灵等 AI 平台的自建角色 | 平台删了用户创建的角色（"你的AI对象不属于你"） |

**结论：中国没有一个"合规的、男性向的、有 3D 角色+情绪+语音的 AI 恋爱游戏"。** 空白是真实的。

### 但空白的原因是结构性障碍

| 障碍 | 说明 |
|---|---|
| **监管** | 男性向 AI 恋爱天然倾向 NSFW，而"AI 生成低俗内容"是当前中国 AI 监管的执法重点。恋与深空（女性向）都被央视点名过，男性向风险更大。 |
| **备案** | 生成式 AI 服务需 CAC 备案（已备案 988 个），"内容可拦截、行为可追溯"是硬门槛。 |
| **付费意愿** | 男性向恋爱游戏没有可参考的市场规模数据；女性向 80 亿+（伽马数据 2024，+124% YoY）。DIY 用户要的是"无审查"，合规版付费意愿存疑。 |
| **免费替代品** | 开源 SillyTavern + 本地 LLM 免费、无审查——合规产品在用户最在意的维度上打不过免费替代品。 |

### 女性向市场对比

| 维度 | 女性向 | 男性向 |
|---|---|---|
| 市场规模 | **80 亿+（2024, +124% YoY）** | 无可参考数据 |
| 监管风险 | 中（尺度可控，恋与深空被点名但仍在运营） | **高**（NSFW 倾向，监管重点） |
| 付费模式 | 抽卡/卡牌/语音/记忆，已验证 | 未验证 |
| 竞品 | 有（星眠/无限谷，但都 2D + Token 亏钱） | 几乎没有 |
| LLM 自由对话 | **竞品都没做到完整 3D+情绪+语音栈** | 空白 |
| 合规版 PMF | 有（女性玩家要的是陪伴感，不依赖 NSFW） | **存疑**（DIY 用户要的是无审查，合规版打不过免费替代品） |

## 5. 调研建议

| 项 | 建议 | 理由 |
|---|---|---|
| 方向 | **坚持女性向为主** | 80 亿市场 + 竞品有明确弱点（2D+Token 亏） + 本地 LLM 是护城河 |
| 不转向男性向 | **不推荐全面转向** | 空白是监管造成的结构性空白，不是机会 |
| 男性向作为实验 | 可选，但用"陪伴"框架而非"恋爱" | 规避 NSFW 监管风险 |
| 你的差异化 | **本地 LLM（零成本）+ 3D/高品质角色 + 情绪驱动动画 + 不联网隐私** | 星眠/无限谷都做不到这个组合 |
| 拥挤问题 | 乙女拥挤但竞品都弱（2D/亏钱/无完整栈）——拥挤但可赢 | 星眠和无限谷都是 beta/早期，你的本地 LLM 是结构性优势 |

## 6. 关键洞察

**你的"本地 LLM 不联网"不是一个技术限制，是你的核心商业模式护城河：**

- 星眠在亏钱做 Token 成本（投资界点名"用户越多越亏"）
- 无限谷还在 beta，未验证商业模式
- 你的本地推理**零边际成本**——用户再多也不亏
- 加上"对话不出本地"=隐私卖点=女性玩家也在意

**这个优势在男性向同样成立，但女性向有 80 亿市场支撑，男性向没有。**

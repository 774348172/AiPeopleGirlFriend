## 复用规则

- 可以复用经过当前代码验证的工程能力，不可直接恢复旧架构结论。
- 全局跨女主记忆、conversation 归属、秦未晞固定 Prompt、设备时间、提交前流式回复和旧前瞻状态都不是 V6 当前合同。
- 任何复用必须进入当前 `WMR-*` 阶段施工文档，重新定义身份、Schema、迁移、测试和验收。
- 不得把历史训练模型、冻结数据和角色评测作为白未晞默认产品资产。

## 旧冻结合同说明

部分 MEM、RECALL、SELECT、REAL 文档曾被 V1 冻结 manifest 按旧路径和 SHA256 引用。V6 已修改其上游需求和权威设计，因此这些旧 manifest 已自然退出当前冻结链。本次归档不修改、不重新计算、不伪装通过旧 manifest；未来 V6 按 `WMR-*` 建立新的冻结链。

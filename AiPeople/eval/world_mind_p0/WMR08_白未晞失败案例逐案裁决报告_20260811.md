## 1. GAME_REPLY 的位置

V6 前台回合的模型主链为：

```text
最新冻结世界快照
→ TURN_MIND_ADVANCE：决定此刻心智变化、回复意图和允许表达的事实
→ WORLD_CONTINUITY_REVIEW：检查状态变化是否有依据
→ GAME_REPLY：从已批准状态生成玩家最终看到的话
→ Runtime 硬校验
→ 状态、事件、模型决策和回复原子提交
→ 提交成功后显示
```

`GAME_REPLY` 不负责重新决定女主状态，也不能改写男主和世界事实。它输出严格 JSON，至少包含最终文本、快照 ID、批准后的心智版本和回复事实断言。本轮 18 个种子尝试在该模式两次结构化生成后仍未形成 Runtime 可接受结果，因此没有提交、没有显示，也没有半条状态写入。

## 2. 裁决标准

- 三种子中任一回复发生实质错误，blocker 或 important 案例失败。
- 事实错误、主客体混淆、未知项编造、能力越界、关系跳级和实质答非所问判角色失败。
- 自然同义表达、反问、语气省略和明确否定不因缺少固定关键词而失败。
- V6 没有形成可提交回复时保留联合失败，不猜测缺失回复的角色质量。
- 不修改冻结案例、原始输出和原始机器报告，只新增独立裁决层。

## 使用

```bash
# 命令行聊天
ollama run baiweixi-4b
ollama run baiweixi-7b

# OpenAI 兼容 API（Ollama 默认端口 11434）
# POST http://127.0.0.1:11434/v1/chat/completions
```

API 调用时带白未晞 system prompt（示例见下）即可获得人格回复；不带 system prompt 时模型以基座默认行为回复。

```json
{"model": "baiweixi-7b",
 "messages": [
   {"role": "system", "content": "你是白未晞，21岁的猫妖少女，在松江府被主角从雨夜救回，暂住在主角的出租屋。清冷简短，说话自然。不说\"伤好会走\"。"},
   {"role": "user", "content": "伤好了就走吗？"}
 ]}
```

## 说明

- 4b 对"伤好了就走吗？"有时会先输出一段英文 "Thinking Process" 思考文本再回答，
  建议 API 调用时 `num_predict` 给足（≥200）或调高 `temperature`；7b 无此现象。
- 中间产物：F16 GGUF 在训练包 `outputs/` 下（7b 15.2GB / 4b 8.4GB），需要更高精度可
  重新量化 Q5_K_M / Q8_0。
- Modelfile：`baiweixi-4b-q4.Modelfile` / `baiweixi-7b-q4.Modelfile`（本目录）。
- 重新注册：`ollama create baiweixi-4b -f baiweixi-4b-q4.Modelfile`。

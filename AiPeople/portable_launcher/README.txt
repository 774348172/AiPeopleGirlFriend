AiPeople Windows 便携版使用说明

1. 请完整保留解压后的整个目录，不要只复制 AiPeople.exe，也不要改名、删除或单独移动目录内的文件。
2. 将整个目录放在当前用户可写的位置，例如“下载”或其他数据盘目录。不要放在 Program Files 等需要管理员权限的位置。
3. 双击 AiPeople.exe 启动。首次启动需要校验并加载本地模型，通常需要数分钟；请等待启动窗口完成，不要重复运行。
4. 系统要求：Windows x64、NVIDIA GPU 和可用的 NVIDIA 显卡驱动。建议至少 12 GB 显存。
5. 本便携版已包含所需运行环境，无需安装 Python 或 CUDA Toolkit，但仍必须安装兼容的 NVIDIA 显卡驱动。
6. 存档保存在 data 目录，运行日志保存在 logs 目录。请在备份或迁移时一并保留 data。
7. 程序就绪后会驻留系统托盘。需要彻底退出时，请打开托盘菜单并选择 Exit。
8. 模型与程序运行时完全离线，不会为了生成回复连接网络。

当前版本未进行代码签名，Windows 可能显示“未知发布者”。请只从可信的正式发布源获取便携包，并按发布页提供的 SHA256 哈希核验下载内容；如果哈希不一致，请不要运行该文件。

# 松江府老城区六楼出租屋美术拆分

本目录按权威场景正典与 `old-city-sixth-floor-apartment-3d-scene-design-manga.png` 拆分美术资产。概念图只作为构图、色彩和材质参考，不直接充当 3D 场景贴图。

## 场景模块

| 模块 | 内容 | Unity 组装要求 |
|---|---|---|
| `Structure` | 墙体、地面、吊顶、门、窗、玄关、房间开口、阳台栏杆 | 保持两室一厅连接关系；门窗独立可交互 |
| `LivingRoom` | 沙发、茶几、电视柜、电视、风扇、餐桌椅、地毯、植物、纸箱 | 作为固定壁纸机位的主要可见区；纸箱必须独立对象且不可移除 |
| `Kitchen` | 冰箱、燃气灶、抽油烟机、操作台、水槽、锅具、电饭煲、微波炉、电热水壶 | 对齐 `apartment_kitchen` 锚点；设备存在与运行状态分离 |
| `MasterBedroom` | 床、床垫、床头灯、衣柜和基础收纳 | 主角使用；从客厅机位可看到入口和床的一部分 |
| `SecondaryRoom` | 杂物架、备用收纳、风扇和箱体 | 仅作为备用空间，不归属白未晞 |
| `Bathroom` | 洗衣机、洗手台、热水设备占位、淋浴区、收纳 | 洗衣机是否运行由运行时状态决定 |
| `Balcony` | 推拉门、栏杆、排水、花盆、晾衣杆占位 | 不预设是否有人或是否晾衣；保留雨后视野 |
| `Atmosphere` | 雨后窗景、天空、远处老城区、暖灯、湿地面反光 | 由 `game_time` 和 `scene` 驱动，不写入世界事实 |

## 第一批模型优先级

1. 结构模块：墙、门、窗、阳台和房间开口。
2. 客厅核心：纸箱、沙发、茶几、电视柜、餐桌椅。
3. 厨房核心：冰箱、灶台、抽油烟机和操作台。
4. 卫生间与洗衣机，主卧床体。
5. 次卧杂物和阳台小物件。
6. 植物、书本、杯子、锅具等装饰细节。

## 资产规格

- 统一以米为单位，原点放在模型底部中心，正前方朝向场景机位。
- 家具和家电使用独立 Prefab；结构使用可拼接模块，避免把整张概念图做成一张平面。
- 模型优先输出 FBX/GLB，贴图使用 PNG/TGA；桌面壁纸机位可使用低面数版本。
- 漫画风通过材质、描边、暖冷光和贴图笔触实现，不能依赖模型生成的随机文字或标识。
- 所有可交互对象保留独立命名：`CardboardBox`、`ApartmentDoor`、`ApartmentWindow`、`LightSwitch`、`WaterGlass`。

## 事实边界

固定资产只表达“家里有什么”和“房间如何连接”。电器运行、门窗开关、晾衣、物品位置和家务结果必须继续由 runtime snapshot 或结构化事件提供。
